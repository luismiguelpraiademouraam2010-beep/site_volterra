# Volterra — Just Dream It

Site demonstrativo de uma marca esportiva fictícia, criado para a atividade de Git e GitHub Pages.

## Arquivos
- `index.html`: conteúdo e estrutura da página.
- `css/style.css`: estilos e responsividade.
- `js/script.js`: menu responsivo.

## Como visualizar
Abra `index.html` no navegador. Para publicar, envie os arquivos a um repositório GitHub e ative GitHub Pages usando a branch `main` e a pasta raiz.

## Observação
Os produtos e a marca são conceituais e fazem parte de um projeto educacional.
